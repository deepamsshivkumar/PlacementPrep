🎓 PlacementPrep

My First Web Development Project

PlacementPrep is a simple student placement preparation website created as a beginner project while learning HTML, CSS, and JavaScript.

📌 About the Project

I created this project to practise my web development skills and understand how to build an interactive website.

The website provides basic aptitude questions, coding practice topics, a study planner, and a simple progress display.

✨ Features

- 🧠 Aptitude Test: Practise 10 basic aptitude questions and calculate your score.
- 💻 Coding Practice: Explore beginner-level programming problems.
- 📝 Study Planner: Add study tasks to a list.
- 📊 Progress Tracking: View the number of questions attempted and correct answers.
- 🎨 Simple Design: Clean layout with styled buttons, cards, and navigation.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Start exploring the aptitude test, coding practice, and study planner.
